DeepSeek 最新开源的 DeepSeek Harness（dsh）来了！这是 DeepSeek AI 官方推出的开源 Agent Harness，采用 Everything is a Plugin 的架构设计，并基于 Cordis 构建，目标是提供一个高度可扩展的 Agent 开发与运行框架。本期视频带大家快速了解 DeepSeek Harness 的整体架构、核心设计理念、插件机制，以及如何通过 npm 或源码方式安装运行 Web UI，同时实测看看这个项目到底能做什么，以及它和我们熟悉的 Claude Code、Codex、OpenCode 等 Agent 工具在思路上有什么不同。目前项目还处于 Developer Preview 阶段，后续还有较大的迭代空间，感兴趣的开发者可以直接关注官方开源仓库。
