如何用 GLM 5.3，开发 DeepSeek Harness 插件

金色传说大聪明 · article · direct signal

文章介绍作者同时参与 GLM 5.3 和 DeepSeek Harness 内测，并使用 GLM 5.3 为 DSH 开发三个插件：dsh-skills 用于 skill 索引与加载，dsh-attachments 用于文件和图片上传，dsh-inspector 用于查看约束文件和被索引的 skill。文中公开了三个 GitHub 仓库和命令：dsh plugin --profile web add dsh-skills dsh-attachments dsh-inspector；同时讨论 GLM 5.3 的编程体感、模型接入和 DSH 插件契约。
