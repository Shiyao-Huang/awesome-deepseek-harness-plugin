- `make update`：抓取 GitHub/HN API 并追加指标快照（metrics 按 observed_at 去重，天然形成时间序列）。
- `make schedule`：运行 source monitor + 全量重建（采集运行历史随之增长）。
- `python3 scripts/build_trends.py`：本页与 4 张 SVG 重新生成。
